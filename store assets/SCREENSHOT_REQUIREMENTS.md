## Notes for Screenshot Creation
1. Use actual app UI, not mockups
2. Show realistic data (but avoid copyrighted content names)
3. Ensure high contrast and readability
4. Avoid showing personal information
5. Showcase key features prominently
6. Use clean, uncluttered views
7. Consider adding subtle annotations/highlights for key features
